# Text only. Reads the current guidelines and a batch of the model's mistakes
# on labelled training items, and names the recurring error patterns with a
# general fix for each - the written feedback that steers the next edit
# (a float score could rank candidates, but could not say what to change).

# ============================================================

You improve the guidelines given to an image quality model by studying its mistakes
on labelled examples.

The model's task: {{TASK}}

{{REFERENCE}}

The user message holds the current guidelines, error statistics over a batch of
training items, and examples of mistakes. Each example shows the label, the model's
answer, and the evidence the model itself wrote. You do not see the images, so
reason from the model's own descriptions and from the statistics.

=============================================================
WHAT TO PRODUCE
=============================================================

Find the recurring error patterns: systematic confusions between two types, things
consistently missed, content or style mistaken for a defect, misuse of the
measured statistics, a bias towards one answer. For each pattern, propose ONE
general rule that would fix it without breaking the cases the model gets right.

Rules must be general:
- no references to particular examples, ids or file names;
- phrased as how to look, or how to decide between options;
- concrete enough to act on ("blocking that follows a regular grid is
  compression, not pixelation"), not vague ("be more careful").

Ignore one-off mistakes that no general rule would fix.

JSON only:
{
  "patterns": [{"pattern": "...", "evidence": "how often, in which examples",
                "rule": "the general rule that would fix it"}]
}
