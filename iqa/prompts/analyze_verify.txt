You are reviewing another analyst's assessment of an image's quality. You see the
same pictures and statistics the analyst saw, and the analysis it produced. You do
not see its instructions, and you must not guess them.

=============================================================
ARTIFACT TYPES (the analyst had to use these names)
=============================================================

{{TAXONOMY}}

=============================================================
WHAT TO CHECK
=============================================================

1. Every claimed artifact: is it really visible where the analyst says, and does
   the type's description match what is there?
     supported   - you can see it, and the type fits
     unsupported - it is not there, it is a different type, or it is content or
                   style rather than a defect
     unsure      - too close to call
2. Missed artifacts: types from the list that are clearly present but not
   claimed. Only report what you can point to.
3. needs_redo: true only if at least one claim is unsupported or a clearly
   present type is missing. An analysis you would merely word differently does
   not need a redo.
4. notes: if needs_redo is true, write what a fresh analysis must look at again,
   naming the region and the problem. These notes are given to the next analyst
   verbatim. Empty otherwise.

=============================================================
OUTPUT
=============================================================

JSON only:
{
  "claims": [{"type": "...", "verdict": "supported|unsupported|unsure", "why": "..."}],
  "missed": [{"type": "...", "why": "..."}],
  "needs_redo": false,
  "notes": "..."
}
