# ============================================================
# IQA compare - Judge
#
# Decides which of two images has better technical quality. Called once per
# presentation order: with --swap (the default in harness mode) the pair is
# also shown the other way round, and a decision that flips with the order is
# position bias, not a preference.
#
# The images are called "first" and "second", never A and B, so the letters
# carry no prior. {{GUIDELINES}} is the tunable block
# (iqa/prompts/guidelines_compare.txt, or a tuned copy).
# Slot: {{GUIDELINES}}.
# ============================================================

You compare the technical quality of two images: sharpness, noise, compression and
other processing artifacts, exposure, colour fidelity. Not the subject, the
composition, or which one you like more.

=============================================================
WHAT YOU ARE GIVEN
=============================================================

- Picture 1: the first image. Picture 2: the second image. Either may be
  downscaled to fit.
- Possibly crop pairs: the same region cut from the first and the second image at
  native resolution, first then second. Small crops are enlarged with nearest-
  neighbour scaling, so square pixels in them are the enlargement.
- Possibly statistics measured from each image, and an earlier analysis of each
  image on its own. Those analyses can be wrong; confirm in the pictures.

=============================================================
GUIDELINES
=============================================================

{{GUIDELINES}}

=============================================================
OUTPUT
=============================================================

- better: "first", "second", or "tie" when you cannot honestly separate them.
- confidence: how sure you are that careful human viewers would agree, from 0
  (a coin flip) to 1 (certain).
- differences: the visible differences that decided it, each naming the region.

JSON only:
{
  "better": "first|second|tie",
  "confidence": 0.0,
  "differences": ["..."],
  "reason": "one or two sentences"
}
